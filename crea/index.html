createfile函数

Windows API 核心文件操作函数 - 安全创建、打开文件及设备句柄的权威指南

什么是 CreateFile 函数？

CreateFile 是 Windows 操作系统中用于创建或打开文件、目录、磁盘卷、控制台、目录流、邮件槽、通信端口以及物理磁盘或磁带驱动器的核心 API 函数。它定义在 kernel32.dll 中，是所有基于 Windows 的文件 I/O 操作的起点。

与简单的文本读写不同，CreateFile 提供了极其强大的功能，包括指定访问模式（读/写/读写）、共享模式、安全属性（权限控制）、文件属性（隐藏/系统）以及文件创建方式（覆盖/新建/追加）。

函数原型与声明

在 C/C++ 中，通常通过包含 windows.h 头文件来使用该函数。函数返回一个句柄，用于后续的读写操作。

C/C++ (Windows API) kernel32.lib 
HANDLE CreateFileA(
  LPCSTR               lpFileName,
  DWORD                dwDesiredAccess,
  DWORD                dwShareMode,
  LPSECURITY_ATTRIBUTES lpSecurityAttributes,
  DWORD                dwCreationDisposition,
  DWORD                dwFlagsAndAttributes,
  HANDLE               hTemplateFile
);

在 C# 中，对应的方法为 System.IO.File.Open 或 System.IO.File.Create，底层实现同样依赖于 Windows API。

关键参数详解

正确理解参数是避免权限错误和文件损坏的关键。

参数名 类型 说明
lpFileName LPCTSTR 目标文件或设备的路径。支持相对路径和绝对路径。
dwDesiredAccess DWORD 访问权限：0（无访问）、GENERIC_READ（读）、GENERIC_WRITE（写）或组合。
dwShareMode DWORD 共享模式：0（独占，其他进程无法打开）、FILE_SHARE_READ、FILE_SHARE_WRITE等。
dwCreationDisposition DWORD 创建行为：OPEN_EXISTING（打开）、CREATE_NEW（新建）、TRUNCATE_EXISTING等。
dwFlagsAndAttributes DWORD 属性：FILE_ATTRIBUTE_NORMAL、FILE_FLAG_OVERLAPPED（异步I/O）等。

完整代码示例：创建并写入文件

以下示例展示如何使用 CreateFile 创建一个新文件，写入数据，并安全地关闭句柄。

C++ 示例代码 
#include <windows.h>
#include <tchar.h>
#include <stdio.h>

void WriteToLogFile() {
    // 1. 调用 CreateFile 创建或打开文件
    // GENERIC_WRITE: 允许写入
    // OPEN_ALWAYS: 如果文件存在则打开，不存在则创建
    // FILE_SHARE_READ: 允许其他进程读取
    HANDLE hFile = CreateFile(
        _T("C:\\Logs\\app_log.txt"),
        GENERIC_WRITE,
        FILE_SHARE_READ,
        NULL,
        OPEN_ALWAYS,
        FILE_ATTRIBUTE_NORMAL,
        NULL
    );

    // 2. 检查句柄是否有效
    if (hFile == INVALID_HANDLE_VALUE) {
        printf("Error opening file: %d\n", GetLastError());
        return;
    }

    // 3. 移动文件指针到末尾（追加模式）
    SetFilePointer(hFile, 0, NULL, FILE_END);

    // 4. 准备要写入的数据
    const char* message = "System initialized successfully.\n";
    DWORD bytesWritten;

    // 5. 写入数据
    if (!WriteFile(hFile, message, (DWORD)strlen(message), &bytesWritten, NULL)) {
        printf("Error writing file: %d\n", GetLastError());
    } else {
        printf("Successfully wrote %d bytes.\n", bytesWritten);
    }

    // 6. 关闭句柄，释放资源
    CloseHandle(hFile);
}

常用访问模式

GENERIC_READ GENERIC_WRITE GENERIC_ALL

创建方式

CREATE_NEW OPEN_EXISTING TRUNCATE_EXISTING OPEN_ALWAYS

安全提示

独占模式

设置 dwShareMode 为 0 时，文件将处于独占状态。此时如果其他程序尝试打开该文件，将收到错误代码 ERROR_SHARING_VIOLATION。

异步 I/O

使用 FILE_FLAG_OVERLAPPED 标志可以启用重叠 I/O，允许在单个线程中处理多个文件操作。

常见问题 (FAQ)

返回 INVALID_HANDLE_VALUE 表示什么？

表示调用失败。必须调用 GetLastError() 获取具体的错误代码（如权限不足、文件路径无效或文件被占用）。

如何读取设备（如串口）？

将设备名作为 lpFileName 参数传入，例如 "COM1" 或 "\\\\.\\PhysicalDrive0"。

与 CreateProcess 有什么区别？

CreateFile 专用于 I/O 操作，返回句柄；CreateProcess 用于启动新的可执行程序，返回进程 ID。
